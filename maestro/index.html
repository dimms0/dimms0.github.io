A closer look

Build SoundFont lists, render MIDI files to audio and run the virtual device, all from one window.

Features

One engine, wherever the MIDI comes from

A game, a DAW, a standalone player or a file on disk — they all reach the same synthesizer, with the same SoundFonts and the same settings.

System-wide virtual device

Anything that can send MIDI can play through Maestro

Multiple synthesis engines

FluidSynth and BASSMIDI and more to come in the future

Idles out of your way

Maestro loads the SoundFonts on-demand depending on the activity from apps

SoundFont lists

Extremely customizable SoundFont loading

Offline MIDI converter

Queue up MIDI files and render them to high quality audio

Event processing

Robust and customizable MIDI event editing / filtering

Good to know

Requirements and licensing

MIDI 2.0 on Windows — MIDI 2.0 functionality is not yet supported on Windows as it requires Windows MIDI Services which are not officially released yet. Once WMS is official, Maestro will ship with full support for WMS and MIDI 2.0 virtual devices.

Licence — Maestro is free software under the GNU LGPL, version 3 or later.

Third-party libraries — FluidSynth (LGPL-2.1-or-later) and Un4seen Developments' BASS, BASSMIDI and BASSFLAC (proprietary, redistributed under Un4seen's own terms) are loaded at runtime and never statically linked. The full notices ship with every build and are in THIRD-PARTY-NOTICES.md.
